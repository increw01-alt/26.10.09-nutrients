## 3. 데이터 파일

```
data/
├─ ingredients.json        성분 사전 (수동 편집)
├─ interactions.json       궁합 쌍 (수동 편집)
├─ guides.json             가이드 콘텐츠 (수동 편집 → build_site.py 가 페이지 생성)
├─ brand-priority.json     검색 순위용 브랜드 가중치 (수동 편집 → 빌드가 검색 색인에 반영)
├─ products.json           제품 목록 중 최신 600건 + 변경 이력·제형 목록 (제품 찾기 첫 화면, gzip 약 33KB)
├─ products/all.json       제품 목록 전체 7,500여 건 (필터·검색·26페이지 이후에서 지연 로드, gzip 약 420KB)
├─ products/names.json     제품명 검색 색인 (검색창을 쓸 때 로드, names-old.json 이 이어 붙음)
├─ products/top/<id>.json  성분별 상위 60개 (성분 상세 페이지용)
├─ products/detail/NN.json 전체 신고 정보 64조각 ('더보기' 펼칠 때 로드)
├─ materials.json          기능성 원료 전체 (인정번호 기준 병합)
├─ materials/<id>.json     성분별 관련 원료
├─ news.json               뉴스
├─ deeplinks.json          쿠팡 파트너스 딥링크 캐시 (키 등록 전까지 비어 있음)
└─ meta.json               빌드·갱신 정보 (푸터 표시, 원료 보유 성분 목록)
```

4. 가이드 추가 후보: 10-16 기준 계획된 후보는 모두 완료(87편). 보류: 코골이·수면무호흡(영양제 범위가 좁음), 1인 가구·식사 불규칙 직장인(직장인 가이드와 중복). 이후 추가는 서치콘솔 '검색어' 보고서와 네이버 키워드 도구에서 실제 유입 검색어를 보고 정함(예: 특정 약 이름+영양제, 특정 증상+영양제 조합 중 기존 가이드가 없는 것). 새 가이드는 `scripts/home_tabs.py` 의 `SHORT`·`ORDER` 에 추가하고 실행해야 홈에 노출됨(현재 87편 전부 노출, `home.js` `GUIDE_GROUPS` 와 `index.html` 정적 카드 동시 생성). 홈 탭은 10-16 접기(더 보기) 적용으로 처리됨
5. 성분 사전 추가 확장 후보: (가) 비타민 단일 페이지는 10-16 완료(B1·B2·나이아신·판토텐산). 베타카로틴(32건)은 비타민A 페이지 별칭으로 처리됨, 비타민K2 단일은 비타민K 페이지가 포괄. (나) 운동·키성장 원료는 10-16 크레아틴·FGO·HT042 추가로 완료. CaHMB(신고 0건)·FSO 근력개선(1건)·HSy2 키성장(8건)·저분자유청단백가수분해물(2건)은 제품이 늘면 추가하고, 추가 시 노인 근감소증 가이드(4번 후보)와 함께. (다) 신고 제품이 있는 원료 우선 — 구아검/구아검가수분해물(2025-03 섭취량 변경 확인 후, 신고 1건), 매스틱 검·히비스커스·그린마테·레드클로버(신고 0건 — 제품이 생기면). 보류 사유가 있는 원료: 알로에 전잎(2024-01-01 기능성 원료 목록 삭제 — 추가 금지), 글루타치온 효모추출물(기능성 원료 아님), 인삼다당체(신고 제품 0건). 기능성 문구·일일섭취량은 `data/materials.json` 과 신고 제품의 기능성 표시, 식약처 고시·행정예고 보도에서 확인한 값만 쓰고, 추가 후 `fetch_products.py --rebuild`·`fetch_drugs.py --rebuild`·빌드, 관련 가이드의 핵심 성분에도 연결. 알로에 겔·프락토올리고당의 일일섭취량은 공전 원문 확인 후 수치로 보강. 재평가·고시 개정으로 수치가 바뀐 원료(스피루리나 2022, 클로렐라·옥타코사놀·구아검 2025-03, 차전자피·프로폴리스 2022)는 공전 개정 때마다 대조. 성분명이 숫자로 끝나면(Q10·B6·D3) 조사 자동 생성 helper 가 받침 없음으로 처리하므로 생성 후 교정
6. 성분·가이드를 늘린 뒤에는 `python scripts/check_site.py` 로 점검한다(10-16 신설, 읽기 전용). 실패 항목(깨진 내부 링크, sitemap↔파일 불일치, JSON-LD 오류, 제목 중복, 홈 탭에 빠진 가이드, 요약 색인 수 불일치)은 바로 고치고, 경고 항목(가이드 핵심 성분에 연결되지 않은 성분, 궁합 3쌍 이하 성분, related 로 아무도 가리키지 않는 가이드, 숫자로 끝나는 성분명의 조사, '미인정' 단정 문장에 인정현황 원료 이름이 보이는 경우)은 검토한다. 10-16 기준 실패 0·경고 0. 자동 수집으로 `materials.json` 이 바뀌면 다시 돌려 새로 인정된 원료가 단정 문구와 어긋나지 않는지 본다. 궁합 데이터에 없는 쌍은 10-19 부터 `data.js` 의 `resolvePair` 규칙 판정으로 표시되므로, 규칙과 다른 판정이 필요한 쌍(특정 성분끼리의 흡수 경쟁·기능성 중복 등 개별 근거가 있는 것)을 발견하면 `interactions.json` 에 넣으면 규칙보다 우선된다. 규칙 자체를 바꿀 때는 `inferPair` 와 `scripts` 쪽 일괄 생성 스크립트의 문구를 맞춘다
7. 운영 중 발견되는 제품 매칭 오탐은 `scripts/fetch_products.py` 의 규칙(`NUTRIENT_RULES`, `HERBAL_RULES`, `EXCIPIENT_RE`, `ADDITIVE_PRONE`) 보정 후 `--rebuild`. 10-15 전수 점검 기준으로 남은 약한 경로는 원재료 앞부분 일치(콜라겐·히알루론산·카르니틴 등 부원료로 든 제품도 연결됨)인데, '함유'로는 사실이라 그대로 둠
8. 검색 순위 브랜드 가중치(`data/brand-priority.json`)는 운영하며 보강 — 앞에 나와야 할 브랜드가 뒤에 보이면 제조사명 앞부분 또는 제품명 키워드로 항목 추가(가중치 3=대표 브랜드, 2=널리 알려진 브랜드, 1=가벼운 우선) 후 빌드. 사이트에 판매량·검색량 데이터가 없어 자동 산정은 하지 않음
9. 의약품 주성분 사전(`scripts/drug_ingr_ko.py` 의 `KO`·`FORM_KO`·`SALT_KO`)과 연결 규칙(`fetch_drugs.py` 의 `NEGATIVE_RULES`(토큰 단위)·`PRODUCT_NEGATIVE_RULES`(주성분 전체 단위)·`is_external_usage`)은 수집으로 새 영문 이름이 들어오거나 오탐이 보이면 보강 후 `python scripts/fetch_drugs.py --rebuild`. 남은 영문 15종(Snake Oil·Rulondin·Tocopherol Preparation, 쉼표로 잘린 'Methyl-N' 등)은 정체가 불분명하거나 원본 토큰 분리 오류라 그대로 둠

### 다른 PC 에서 이어서 작업하기 (10-16 기준)

1. 저장소 받기: `git clone https://github.com/increw01-alt/26.10.09-nutrients.git` 뒤 작업 브랜치 `claude/supplement-info-compatibility-site-1o2qrj` 로 체크아웃(기본 브랜치이자 Cloudflare Pages 배포 브랜치). 이미 받아 둔 PC 라면 `git pull` 만.
2. 준비물: Python 3.11+ 와 `pip install -r requirements.txt`(openpyxl 은 머천트 엑셀을 읽을 때만 필요). Node 는 Tailwind 클래스나 아이콘을 바꿀 때만(`npm run assets`) 필요하고, 없으면 push 후 GitHub Actions 가 자산을 재생성해 커밋한다.
3. 비밀값은 저장소에 없다: `.env`(식약처·공공데이터·네이버 API 키)는 수동 수집에만 필요하고 매일 03:15 KST 자동 수집이 GitHub Secrets 로 돈다. 쿠팡 파트너스 키도 GitHub Secrets 에 넣는다. 링크프라이스 어필리에이트 ID 는 공개 값이라 `assets/js/config.js` 에 있다.
4. 작업 순서: `git pull` → 데이터·템플릿 수정 → `python scripts/build_site.py` → `python scripts/check_site.py`(실패 0 확인) → 로컬 서버로 화면 확인 → 커밋(한국어)·푸시. 생성 파일(i/·guide/·guides.html·sitemap.xml·data/meta.json·data/guides-index.json·HTML 의 `?v=` 해시)이 함께 바뀌는 것이 정상.
5. Claude Code 로 이어서 할 때: 이 문서의 7절(다음 할 일)과 CLAUDE.md 의 '작업 요령'이 이전 세션의 맥락을 대신한다. 10-16 기준 계획된 콘텐츠 확장(성분 81·궁합 369·가이드 87)은 끝났고, 남은 것은 운영 점검과 사용자 몫(서치콘솔·서치어드바이저 재제출, 쿠팡 파트너스 최종승인·API 키, 11번가 링크프라이스 승인 대기, 저장소 공개 범위, 저작권 등록).
