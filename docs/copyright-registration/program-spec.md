# 프로그램 명세서 — 영양제.kr 웹사이트 프로그램

(컴퓨터프로그램저작물 등록 첨부용. 수치는 2026-10-15 기준이며 제출 시 `out/날짜/MANIFEST.txt` 값으로 갱신)

## 1. 개요

영양제.kr 웹사이트 프로그램은 영양제(건강기능식품) 성분의 기능성·권장량·주의사항과 성분 간 궁합, 복용 시간·순서를 안내하는 정보 제공 웹 애플리케이션이다. 이용자가 성분·제품·의약품을 검색해 조합을 고르면 사전 정리된 궁합 데이터로 시너지·주의 조합을 판정하고 하루 복용 시간표를 만들어 보여 준다. 식약처 건강기능식품 품목제조신고 정보와 의약품 허가정보를 수집해 제품·의약품의 원재료 문구에서 영양 성분을 자동 추출·연결하는 수집 프로그램, 데이터를 검증해 성분·가이드 페이지와 검색 색인·sitemap 을 생성하는 빌드 프로그램, 브라우저에서 동작하는 화면 프로그램으로 구성된다. 프레임워크·번들러 없이 정적 HTML·CSS·JavaScript 로 작성되어 정적 호스팅(Cloudflare Pages)에서 동작한다.

## 3. 구성 (모듈별 역할)

### 3-1. 화면 프로그램 (`assets/js/`, 약 2,400줄)

| 파일 | 역할 |
|---|---|
| `config.js` | 브랜드·도메인·문의·제휴 ID 등 전역 설정. 한 곳에서 바꾸면 전 페이지에 반영 |
| `data.js` | JSON 데이터 로더·캐시. 한글을 초·중·종성 자모로 분해해 비교하는 검색 매처(`nameMatcher`·`has`·`markMatch`)로 '락ㅌ'·'ㄹㅌㅍ' 같은 미완성 입력도 제품명과 맞춘다. 이름 앞부분 → 단어 첫머리 → 이름 중간 → 제조사명 순의 일치 등급과 브랜드 가중치로 결과를 정렬. 제품 검색 색인은 최근 3년분을 먼저 받고 과거분을 뒤에 합친다 |
| `layout.js` | 공통 헤더·푸터·전역 검색 오버레이(자동완성: 성분·제품·의약품·가이드)·메뉴·모바일 하단 탭 바를 생성. 문의 이메일 등 설정값을 화면에 주입 |
| `schedule.js` | 선택한 성분들의 섭취 시간대(공복·식후·취침 전 등)와 상호 주의 쌍을 고려해 하루 복용 시간표를 배치 |
| `illus.js` | 성분명이 적힌 병·캡슐 SVG 일러스트와 분류별 연출 이미지를 코드로 생성 |
| `affiliate.js` | 쇼핑 검색 링크 생성과 제휴 딥링크 감싸기(의약품에는 적용하지 않음) |
| `pages/home.js` | 메인: 검색창 자동완성, '빠른 궁합 체크'(성분·제품·의약품 혼합 선택 → 조합 계산 → 궁합 페이지 또는 의약품 조합 블록으로 이동), 카테고리·추천·가이드 탭 |
| `pages/compat.js` | 궁합 체크: 성분 선택 타일, 조합별 시너지·주의 판정, 결과 요약·조합 카드·복용 시간표·관련 제품 |
| `pages/ingredient.js` / `ingredients.js` | 성분 상세(기능성·권장량·상한·섭취 시간·궁합·관련 제품·인정 원료)와 성분 사전 목록 |
| `pages/products.js` / `product.js` | 제품 찾기(성분·분류 필터, 지연 로드)와 제품 상세(함유 성분·함께 먹으면 좋은 성분·주의 조합·신고 정보) |
| `pages/drug.js` | 의약품 상세: 주성분의 한글 표시, 연결된 영양 성분, '함께 챙기면 좋은/주의할 영양 성분' 규칙 표시, 선택한 영양제와의 조합 블록 |
| `pages/search.js` | 통합 검색 결과(섹션별), 결과 없을 때 비슷한 이름 제안·검색 요령 |
| `pages/guide.js` / `materials.js` / `news.js` | 가이드 본문, 기능성 원료 인정현황, 뉴스 목록 |

### 3-2. 빌드 프로그램 (`scripts/build_site.py`, `brand_priority.py`, `common.py`)

- 데이터 파일(성분·궁합·가이드·의약품 연결 규칙)의 id 참조·필수 항목을 검증하고 오류가 있으면 빌드를 중단한다.
- 성분 43종의 상세 페이지(`i/*.html`), 가이드 40편(`guide/*.html`)과 목록, `sitemap.xml`, 빌드 메타(`data/meta.json`)를 템플릿으로 생성한다.
- 제품 상세 조각에서 검색용 경량 색인(`products/names.json`·`names-old.json`)을 만들고, 브랜드 우선순위 규칙을 색인 항목에 실어 둔다.
- 모든 HTML 의 자산 링크에 내용 해시를 붙여 캐시를 무효화하며, 줄끝을 정규화해 OS 가 달라도 같은 해시가 나오게 한다.
- canonical·OG·구조화 데이터 주소를 호스팅 규칙(확장자 없는 주소)에 맞게 생성한다.

### 3-3. 수집 프로그램 (`scripts/fetch_*.py`, `drug_ingr_ko.py`, 약 2,900줄 중 대부분)

- `fetch_products.py`: 식약처 품목제조신고 정보를 역순·재시도·대기 제어로 수집하고, 원재료·기능성 문구에서 영양 성분을 추출하는 규칙(`NUTRIENT_RULES`·`HERBAL_RULES`), 부형제·첨가물 오탐 제외 규칙(`EXCIPIENT_RE`·`ADDITIVE_PRONE`), 영문 약어 단어 경계 처리로 제품을 성분 사전에 연결한다. 결과를 목록·성분별 상위·상세 조각으로 분할 저장한다.
- `fetch_drugs.py`: 의약품 허가정보와 e약은요 정보를 수집하고 주성분(영문·염 표기)을 영양 성분에 연결하는 규칙(`SALT_RULES`·`CONTAIN_RULES`·`NEGATIVE_RULES`), 외용제 판정, 영문 주성분 → 한글 표시 사전(`drug_ingr_ko.py`)을 적용한다.
- `fetch_materials.py`: 기능성 원료 인정현황을 수집해 인정번호 기준으로 병합하고 성분 사전과 매칭한다.
- `fetch_news.py`, `build_affiliate_links.py`, `make_og_image.py`, `build_icons.mjs`: 뉴스 수집·요약 중복 정리, 제휴 딥링크 생성, 소셜 썸네일 렌더링, 사용 아이콘만 담은 번들 생성.

### 3-4. 화면·스타일 (`*.html` 15면, `assets/css/style.css`·`home.css`·`tailwind.src.css`)

메인·성분 사전·성분 상세·궁합 체크·제품 찾기·제품 상세·의약품 상세·기능성 원료·뉴스·가이드 목록·통합 검색·소개·이용약관·404 페이지. 딥 그린·크림·피치 색 체계, 상단 밴드·제목 묶음·버튼·성분 카드의 공통 스타일, 고정 헤더 높이 변수와 섹션 이동 탭.

## 4. 주요 기능과 처리 흐름

1. **검색**: 입력 → 자모 분해 → 성분·제품·의약품·가이드 색인과 등급별 일치 판정 → 브랜드 가중치 정렬 → 자동완성 또는 통합 검색 결과 페이지.
2. **궁합 판정**: 선택 항목(성분·제품·의약품) → 각 항목에 연결된 영양 성분 묶음으로 전개 → 모든 쌍을 궁합 데이터와 대조해 시너지·주의·중립 판정 → 요약 카드·조합 카드 → 복용 시간표 배치.
3. **의약품 조합**: 의약품의 주성분 → 영양 성분 연결 → 연결이 없으면 의약품 연결 규칙(주성분 영문·분류 기준)으로 상대 영양제를 판정 → 의약품 상세의 조합 블록으로 이동.
4. **데이터 갱신**: 매일 자동 수집 → 매칭 규칙 적용 → 분할 저장 → 커밋 → 호스팅 자동 배포.
5. **페이지 생성**: 데이터 검증 → 템플릿 렌더링 → 색인·sitemap·메타 생성 → 자산 해시 부여.
