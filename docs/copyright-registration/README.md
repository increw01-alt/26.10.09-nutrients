# 영양제.kr 저작권 등록 준비 자료

한국저작권위원회 저작권등록 시스템(https://www.cros.or.kr)에 **컴퓨터프로그램저작물**과 **데이터베이스제작자의 권리**를 등록할 때 쓰는 준비 자료입니다. 등록은 권리 발생 요건이 아니라(저작권은 창작과 동시에, 데이터베이스제작자의 권리는 제작 완료와 동시에 생김) 분쟁에 대비한 **증거 확보** 절차입니다.

| 파일 | 용도 |
|---|---|
| `README.md` (이 파일) | 절차, 신청서 기입 초안, 주의사항 |
| `program-spec.md` | 프로그램 명세서(기능 설명서) — 프로그램 등록 첨부용 |
| `database-spec.md` | 데이터베이스 설명서 — 데이터베이스 등록 첨부용 |
| `scripts/make_copyright_bundle.py` | 제출용 복제물(소스 zip·소스 목록·데이터 zip·CSV·체크섬)을 `out/날짜/` 에 생성 |

`out/` 은 생성물이라 git 에 올리지 않습니다(`.gitignore`). 제출 직전에 다시 생성해 최신 상태를 내면 됩니다.

```bash
python scripts/make_copyright_bundle.py
```

## 1. 왜 두 건으로 나누는가

| 구분 | 대상 | 근거 | 보호기간 |
|---|---|---|---|
| 컴퓨터프로그램저작물 | `assets/js`·`assets/css`·`scripts/*.py`·HTML 템플릿 등 직접 작성한 코드 | 저작권법 제2조 제16호, 제4조 제1항 제9호 | 저작자 사후 70년(업무상저작물은 공표 후 70년) |
| 데이터베이스 | `data/ingredients.json`·`interactions.json`·`guides.json`·`drug-pairings.json`·`brand-priority.json` 등 직접 선택·배열·검증한 수동 데이터 | 저작권법 제4장(제91조~) 데이터베이스제작자의 보호 | 제작 완료 다음 해부터 5년, 상당한 갱신이 있으면 그 부분은 다시 5년(제95조) |

프로그램과 데이터베이스는 저작물 종류가 달라 한 건으로 묶을 수 없습니다. 가이드 40편의 본문 자체를 **어문저작물(또는 편집저작물)**로 한 건 더 등록할 수도 있는데, 데이터베이스 등록으로 전부·상당 부분 복제는 이미 막을 수 있으므로 선택 사항입니다.

보호되지 않는 것도 분명히 해 둡니다. 식약처·공공데이터포털에서 수집한 원본 데이터(`data/products*`, `data/drugs/*`, `data/materials.json`, `data/news.json`)와 과학적 사실 자체는 등록 대상이 아니며, 번들에서도 제외합니다.

## 2. 절차 (cros.or.kr)

1. 회원가입 후 본인인증. 사업자(법인) 명의로 등록하려면 사업자 회원으로 가입하고 업무상저작물로 신청합니다.
2. **등록신청 → 저작권등록** 에서 저작물 종류를 고릅니다. 프로그램은 "컴퓨터프로그램저작물", 데이터는 "데이터베이스".
3. 등록 사항은 **저작권(저작재산권) 등록 + 창작연월일 등록 + 최초공표연월일 등록**을 함께 신청합니다. 등록된 연월일은 그 날 창작·공표된 것으로 추정됩니다(제53조 제3항).
4. 신청서를 아래 초안으로 채우고 복제물·명세서를 첨부합니다. 첨부 형식(pdf·hwp·doc·txt·zip 등)과 용량 한도는 신청 화면의 안내를 따릅니다. `.md` 파일은 같은 내용의 `.txt` 로 번들에 함께 들어가므로 그것을 올리거나, 브라우저 인쇄로 PDF 로 바꿔 올립니다.
5. 수수료 납부. 온라인 신청 기준 데이터베이스 23,600원, 컴퓨터프로그램 53,600원(수수료 + 등록면허세, 2026-10-15 수수료 안내 확인). 신청서 작성 뒤 자동 산출된 금액을 카드·계좌이체·무통장·휴대폰으로 결제해야 접수가 완료됩니다.
6. 심사(보통 며칠~2주, 보정 요구가 올 수 있음) 뒤 전자 등록증을 내려받아 `docs/` 가 아닌 **개인 보관 위치**에 둡니다(등록번호만 PROJECT-STATUS 에 기록).

등록의 효과: 등록 저작권을 침해한 자는 과실이 있는 것으로 추정되고(제125조 제4항), 등록된 저작자·창작일·공표일이 추정되어 침해 소송·게시중단 요청에서 입증 부담이 크게 줍니다.

## 5. 주의사항

- **개인정보를 저장소에 넣지 않습니다.** 저장소는 PUBLIC 입니다. 신청인 정보·등록증·결제 내역은 신청 화면과 개인 보관 위치에만 둡니다.
- 데이터베이스는 계속 바뀌므로 **큰 갱신(성분·가이드 대량 추가) 뒤에는 다시 등록**해야 그 부분도 보호기간이 새로 시작됩니다. 분기 1회 정도가 적당합니다.
- 번들의 소스 zip 에는 생성 파일(`i/`, `guide/`, `guides.html`, `sitemap.xml`, `assets/css/tailwind.css`, `assets/js/icons.js`)과 제3자 자산(Pretendard 글꼴, lucide 아이콘 데이터, 사진)을 넣지 않습니다. 직접 그린 SVG 일러스트는 `assets/js/illus.js` 안에 코드로 들어 있으므로 프로그램 등록에 포함됩니다.
- 특허·상표와 달리 저작권 등록은 심사관이 신규성을 보지 않습니다. 등록되었다는 사실이 "독창적이다"를 뜻하지는 않으며, 분쟁 때 입증을 돕는 수단입니다.

## 6. 등록 사이트에서 확인한 사항 (2026-10-15, cros.or.kr)

- 메뉴 경로: **등록신청 → 저작권(컴퓨터프로그램) 등록**, **등록신청 → 데이터베이스제작자권리 등록**. 메인 화면의 '컴퓨터프로그램 등록' 타일은 전자이고, 데이터베이스는 '일반저작물 등록' 쪽이 아니라 데이터베이스제작자권리 메뉴를 써야 합니다.
- 온라인 신청 흐름: 신청서류 작성 → 구비서류·복제물 제출(스캔·파일 업로드) → 본인확인(공동인증서 등)·수수료 결제 → 접수 완료(접수번호 부여). 결제까지 끝나야 접수입니다.
- '1저작물 1등록부' 원칙: 프로그램 1건, 데이터베이스 1건을 각각 신청합니다.
- 수수료(온라인, 건당): 데이터베이스제작자권리 20,000원 + 등록면허세 3,600원 = **23,600원**. 컴퓨터프로그램저작물 50,000원 + 3,600원 = **53,600원**. 둘 합계 77,200원. 심사 반려 시 등록면허세만 반환되고 수수료는 반환되지 않습니다.
- 작업 시간 1시간이 지나면 자동 회원 나가기가 되고 작성 중인 신청서는 사라집니다. 오른쪽 '시간연장'을 눌러 가며 작성하고, 임시저장은 '나의저작권 > 신청서 보관함'에서 이어 쓸 수 있지만 **임시저장은 접수가 아닙니다**.
- 법인·개인사업자 명의 등록은 가능하나 저작자(창작자)를 법인으로 하려면 업무상저작물이어야 합니다. 개인 명의가 단순합니다.
- 등록 상담 1800-5455. 생성형 AI 활용 저작물 등록 안내서는 고객센터 > 공지사항(2025-06-30) 에서 내려받을 수 있습니다.

## 7. 생성형 AI 활용 표시 (반드시 읽을 것)

이 사이트의 코드와 설명 글은 상당 부분을 생성형 AI(Claude Code)로 만들었습니다. 한국저작권위원회는 2025년 6월 '생성형 인공지능(GAI) 활용 저작물의 저작권 등록 안내서'를 내고, **AI 산출물 자체는 등록할 수 없고** 인간의 창작적 표현이 포함된 'GAI 활용 저작물'만 그 **인간이 기여한 부분에 한해** 등록할 수 있다고 안내합니다. 단순한 지시(프롬프트) 입력은 아이디어 제공으로 보아 창작적 기여로 인정하지 않고, 결과물을 반복 수정·선택·배열해 의도한 표현을 구현한 부분을 기여로 봅니다. AI 활용 사실을 숨기고 등록하면 허위 등록(저작권법 제136조 제2항)이 될 수 있으므로 신청서에 활용 사실을 적습니다.

두 건의 성격이 다릅니다.

- **데이터베이스제작자의 권리**는 창작성이 아니라 "소재의 제작·갱신·검증·보충에 든 상당한 투자"를 보호합니다. 어떤 도구로 소재를 만들었는지는 요건이 아니므로, AI 활용을 밝혀도 등록에 지장이 없습니다. **이 건을 먼저 신청**하는 것이 안전합니다.
- **컴퓨터프로그램저작물**은 창작적 표현이 필요합니다. 요구사항 정의·구조 설계·기능 선택·반복 수정 지시·검수·데이터 규칙 설계처럼 신청인이 주도한 부분을 구체적으로 적어야 하고, 위원회가 AI 산출물로 보면 반려되거나 일부만 등록될 수 있습니다. 신청 전에 안내서를 읽고 애매하면 1800-5455 에 "GAI 활용 프로그램 등록" 으로 상담하는 편이 수수료(반환 불가)를 아낍니다.

신청서·명세서에 넣을 문안 초안:

> 본 저작물은 생성형 인공지능(Anthropic Claude, Claude Code)을 활용해 제작했습니다. 신청인은 사이트의 목적과 기능 범위, 성분·궁합·가이드 데이터의 선정 기준과 표현 원칙(식약처 인정 기능성 범위 준수 등), 화면 구조와 디자인 방향을 정하고, 생성된 코드·문안을 검토해 수정·재생성을 반복 지시하며 최종안을 선택·배열했습니다. 식약처·공공데이터포털 자료와 대조한 검증과 배포·운영도 신청인이 수행했습니다. 인간의 창작적 기여 부분: 요구사항·구조 설계, 데이터 선정·배열·검증 기준, 반복 수정 지시와 최종 선택. (실제로 직접 고친 파일·부분이 있으면 여기에 구체적으로 추가)
