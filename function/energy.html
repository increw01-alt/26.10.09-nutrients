    비타민 B6 + 마그네슘

    비타민 B군 (B 컴플렉스) + 마그네슘

    탈모 관리에서 함께 확인하는 조합

  • 좋은 궁합

    비타민 B1 (티아민) + 비타민 B2 (리보플라빈)

    에너지 대사 보조효소 조합

  • 좋은 궁합

    비타민 B1 (티아민) + 마그네슘

    티아민을 활성형으로 바꾸는 데 마그네슘이 필요해요

  • 좋은 궁합

    비타민 B2 (리보플라빈) + 비타민 B6

    B6 를 활성형으로 바꾸는 데 B2 가 필요해요

  • 좋은 궁합

    비타민 B2 (리보플라빈) + 철분

    철 이용을 돕는 조합

  • 좋은 궁합

    판토텐산 (비타민 B5) + 비타민 B1 (티아민)

    에너지 생성 경로를 함께 돕는 B군 짝

  • 좋은 궁합

    판토텐산 (비타민 B5) + 비타민 B2 (리보플라빈)

    에너지 생성 경로의 B군 짝
