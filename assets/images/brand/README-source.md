# 영양제.kr 아이콘 · SVG / 파비콘 / 앱 아이콘

이 파일은 공유해 주신 ‘잎사귀가 어우러진 캡슐’ 이미지를 바탕으로 색상·형태를 추적해 만든 벡터 기반 SVG입니다. 원본 이미지의 완전 동일한 소스 파일이 아니라 정밀하게 재구성한 버전입니다.

파일 용도
- yeongyangje-icon.svg : 웹사이트 파비콘, 로고 등 (둥근 모서리·투명 코너)
- favicon.ico : 기존 브라우저 호환
- icon-16.png, icon-32.png, icon-48.png : 소형 아이콘
- icon-180.png : 기본 iOS 홈 화면 아이콘
- pwa-icon-180.png, pwa-icon-192.png, pwa-icon-512.png : 앱 설치용(전체 배경)
- yeongyangje-icon-fullbleed.svg : 플랫폼에서 모서리를 자동으로 자르는 앱 아이콘에 최적화
- yeongyangje-icon-maskable.svg / pwa-maskable-512.png : 안드로이드 마스킹 안전영역 적용 버전
- favicon-snippet.html : HTML head 설정 예시
- site.webmanifest : PWA 앱 설치 메타데이터
- icon-preview.html : 다양한 크기의 미리보기

웹사이트의 /public 또는 정적 자산 루트 경로에 파일을 복사한 뒤 HTML head에 favicon-snippet.html의 내용을 붙여 넣습니다.
